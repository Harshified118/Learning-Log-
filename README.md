# Learning Log

A daily learning log documenting my journey as a B.Tech Computer Science student diving deep into software development, problem-solving, and computer science fundamentals.

## What I Cover

- **Python**: Core programming concepts, the standard library, scripting, and object-oriented design.
- **Data Structures & Algorithms (DSA)**: Fundamental data structures, algorithmic paradigms, problem-solving patterns, and time/space complexity analysis.
- **Frontend Basics**: Core web technologies including semantic HTML5, modern CSS3 (Flexbox, Grid), and vanilla JavaScript.
- **Linux**: Workflow on Fedora Linux, command-line tooling, bash scripting, and system navigation.

## How I Learn

- **Official Documentation First**: Prioritizing primary sources and official documentation to understand tools, specifications, and language behaviors from the ground up.
- **Hands-on Practice**: Writing code, building minimal projects, and solving DSA problems daily.
- **Active Reflection**: Documenting what was studied, what was built, pain points encountered, and key takeaways each day.
